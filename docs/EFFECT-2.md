# Effect 2.0 — архитектура и план

Effect — отдельный ИИ-продукт: из слов пользователя он собирает сайт, лендинг, презентацию, игру, приложение или дашборд. Готовых шаблонов нет: каждый проект пишут агенты. Этот документ — источник правды для кода в `lib/effect/agent/*`, `components/effect/studio/*`, `api/effect.mjs` и `artifact/effect/*`.

## 1. Что меняется по сравнению с 1.x

| Было | Стало |
|---|---|
| Мгновенный движок с шаблонами (`engine.ts`, `render-*.ts`, `content.ts`) | Удалён. Все проекты пишет ИИ по словам пользователя |
| Режимы «⚡ Мгновенно» / модель, выбор типа проекта | Один композер. Роутер сам решает: новый проект, правка или вопрос; сам определяет тип |
| Модели «Focus Astrolabe / Compass / Spyglass» | **Effect Astrolabe**, **Effect Compass**, **Effect Spyglass** + каталог OpenRouter на сайте |
| Один вызов модели | Команда агентов: Архитектор → Дизайнер → Разработчик → Тестировщик → исправления |
| Артефакт без ИИ | В артефакте всё работает через возможность `sample` — на тарифе Claude зрителя, без ключей |

### 2.1. Транспорт: один конвейер — два мира

Конвейер ничего не знает о сети. Ему передают функцию

```ts
type CallFn = (model: string, messages: Msg[], opts: CallOpts) => Promise<CallResult>;
// Msg       = { role: 'system' | 'user' | 'assistant'; content: string }
// CallOpts  = { role: Role; effort: Level; signal?: AbortSignal; onText?(whole: string): void; maxTokens?: number }
// CallResult= { text: string; truncated: boolean; usage?: {input, output}; model?: string }
```

- **Артефакт**: `call` → `claude.use('sample')` → `sample(input, {modelTier, effort, onText, signal, cache: false})`. Системное сообщение становится первым user-ходом (у `sample` нет system). Spyglass → `quick`, Compass → `default`, Astrolabe → `complex`. Усилие: Быстро → `low`, Вдумчиво → `medium`, Глубоко и Ultra → `high` (Ultra добавляет раунд ревью). OpenRouter в артефакте недоступен (сеть закрыта) и показан как «на сайте Effect».
- **Сайт**: конвейер тоже работает в браузере, а `call` делает `POST /api/effect {op: 'step', role, ctx, model, effort}`. Сервер сам собирает промпт роли из `ctx` той же функцией `buildMessages`, поэтому клиент не может подсунуть свой системный промпт, а ключи не покидают сервер. Ответ — поток NDJSON (см. §4).
  Почему конвейер не целиком на сервере: полный прогон (5–7 вызовов, Разработчик пишет 30–80 КБ кода) длиннее лимита функции Vercel (300 с). Пошаговые запросы укладываются в лимит, а если шаг всё же обрывается по времени, сервер отдаёт `done {truncated: true}` и клиент продолжает генерацию с места обрыва.
- **Полный серверный прогон** тоже есть: `POST /api/effect {op: 'run', request, project?}` гонит тот же `runPipeline` на сервере и стримит события конвейера (для интеграций и тестов; длинные проекты могут упереться в лимит времени).

## 3. Роутер

`route(text, {project, choice})` → `Route`:

```ts
type Route = {
  intent: 'new' | 'edit' | 'question';
  kind: 'website' | 'landing' | 'presentation' | 'game' | 'app' | 'dashboard' | 'other';
  complexity: 1 | 2 | 3;          // 1 — простая правка/малый проект, 3 — большой многостраничный проект, игра с уровнями
  confidence: number;             // 0..1; ниже 0.6 — спросить модель-роутер (Spyglass, JSON)
  effort: 'quick' | 'thoughtful' | 'deep' | 'ultra';   // итоговое (после «Авто»)
  steps: StepPlan[];              // какие агенты и на каких моделях
  reason: string;                 // одна строка для пользователя: «Новая игра · Effect Astrolabe · Глубоко»
};
```

Эвристика (без сети, мгновенно):
1. Нет проекта → `new`.
2. Вопрос: знак вопроса или начало «как/что/почему/зачем/можно ли/what/how/why…» и нет глаголов действия («сделай, добавь, измени, убери, поменяй, перепиши, исправь…») → `question`.
3. Явный новый проект: «новый/другой/с нуля/ещё один» или глагол создания + существительное типа, которое отличается от текущего типа («сделай игру», когда открыт сайт) → `new`.
4. Иначе — `edit`.
5. Тип — по словарю основ («сайт, лендинг, презентац, слайд, игр, приложени, калькулятор, трекер, дашборд, панель, аналитик, crm…» и английские аналоги); при правке — тип текущего проекта.
6. Сложность — длина запроса, перечисления, слова «многостраничный, уровни, физика, мультиплеер, 3D, CRM, личный кабинет, графики».
7. Низкая уверенность (правка с глаголом создания и тем же типом, очень короткая фраза при открытом проекте) → один быстрый вызов модели-роутера, ответ JSON `{intent, kind}`.

Авто-выбор (если пользователь не выбрал модель и усилие вручную):

| Ситуация | Усилие | Модели шагов |
|---|---|---|
| Вопрос | Быстро | Ответ — Spyglass |
| Правка, сложность 1 | Быстро | Разработчик — Compass, Тестировщик — пропуск (только статические проверки) |
| Правка, сложность 2–3 | Вдумчиво | Разработчик — Compass, Тестировщик — Spyglass |
| Новый проект, сложность 1 | Вдумчиво | Архитектор + Дизайнер — Spyglass, Разработчик — Compass, Тестировщик — Spyglass |
| Новый проект, сложность 2 | Вдумчиво | Архитектор — Compass, Дизайнер — Spyglass, Разработчик — Astrolabe, Тестировщик — Compass |
| Новый проект, сложность 3 / игра | Глубоко | Архитектор — Astrolabe, Дизайнер — Compass, Разработчик — Astrolabe, Тестировщик — Compass |

Ручной выбор модели ставит её на все шаги. Ручное усилие ставится на все шаги. Ultra = «Глубоко» на всех шагах + раунд «Ревьюер» после тестов.

Пропуск шагов: «Быстро» для нового проекта объединяет Архитектора и Дизайнера в один шаг; правки идут Разработчик → Тестировщик; Тестировщик пропускается на правках сложности 1 при «Быстро»; раунд исправлений запускается только если Тестировщик нашёл критичные или важные проблемы (не более 2 раундов, на правках — 1).

## 4. Протокол событий

События конвейера (`onEvent` в браузере, NDJSON-строки у `op: 'run'`):

```jsonc
{"type":"route","route":{...Route}}
{"type":"step","id":"architect","role":"architect","status":"start","title":"Архитектор","model":"compass","at":1732600000000}
{"type":"text","id":"architect","delta":"..."}          // поток текста шага
{"type":"progress","id":"developer","chars":18342,"note":"Пишу код…"}
{"type":"html","html":"<!doctype html>…","final":false} // промежуточное превью (не чаще раза в 1,2 с)
{"type":"step","id":"architect","status":"done","ms":8123,"summary":"5 страниц, 14 функций","output":"{…}"}
{"type":"step","id":"tester","status":"skipped","reason":"Быстрая правка — только статические проверки"}
{"type":"step","id":"developer","status":"error","message":"…"}
{"type":"done","html":"<!doctype html>…","reply":"…","spec":{…},"design":{…},"report":{…}}
{"type":"error","code":"not_granted","message":"…"}
```

Пошаговый эндпоинт `op: 'step'` отдаёт события одного вызова модели:

```jsonc
{"type":"start","model":"Effect Compass"}
{"type":"text","delta":"..."}
{"type":"done","truncated":false,"usage":{"input":1234,"output":5678},"stop":"end_turn"}
{"type":"error","code":"busy|refused|failed|no_key|bad_request","message":"…"}
```

`GET /api/effect` → `{ai, providers: {anthropic, openrouter}, models: [...Effect], env: ['ANTHROPIC_API_KEY', 'OPENROUTER_API_KEY']}`; `GET /api/effect?catalog=openrouter` → кэшированный (1 ч) список моделей OpenRouter `{id, name, provider, context, prompt, completion}`.

## 5. Агенты и их промпты (суть)

Все промпты на английском (модели точнее следуют), весь видимый текст — на языке пользователя. Полный текст — `lib/effect/agent/prompts.ts`.

- **Архитектор** — JSON-спецификация: название, тип, язык, аудитория, цель, тон; страницы и разделы с реальным содержанием; функции и интерактив; данные; критерии приёмки. Для игр — гейм-дизайн: жанр, основной цикл, управление (клавиатура и тач), сущности, прогрессия, очки, «сочность» (частицы, тряска, звук), состояния.
- **Дизайнер** — JSON дизайн-системы уровня Apple: направление и обоснование в одну строку, палитра (с проверенным контрастом), пара шрифтов Google Fonts, шкала типографики, отступы, радиусы (squircle), движение (кривые, длительности, поэтапное появление), компоненты.
- **Разработчик** — один полный HTML-файл (`<!doctype html>` … `</html>`), инлайн CSS/JS, только Google Fonts и cdnjs с точной версией, без внешних картинок, адаптив от 360 px, доступность, `prefers-reduced-motion`, работающие функции без заглушек. Если ответ обрезан — конвейер просит продолжить с места обрыва и склеивает (до 4 продолжений).
- **Тестировщик** — получает спецификацию, результаты статических проверок и код; ищет баги, поломки вёрстки на 390 и 1440 px, проблемы доступности и недоделанные функции. Ответ — JSON `{verdict: "pass"|"fix", summary, issues: [{severity, area, problem, fix}]}`.
- **Ревьюер** (только Ultra) — арт-директор и продакт: полировка, UX, тексты, движение. JSON того же вида.
- **Ответ** — отвечает на вопрос о проекте или о том, что умеет Effect, коротко и по делу.
- **Роутер** — при низкой уверенности: JSON `{intent, kind}`.

## 6. Игры

Руководство для игр требует: цикл `requestAnimationFrame` с delta time и ограничением шага, canvas по размеру окна и `devicePixelRatio`, состояния (титул, игра, пауза, конец, рестарт), пауза при скрытой вкладке, Web Audio только после первого ввода и кнопка звука, управление с клавиатуры и сенсорное (зоны/кнопки/джойстик), рекорд в `localStorage` внутри try/catch, растущая сложность, частицы и тряска экрана, читаемый HUD от 360 px.

## 7. Студия

- Слева — проекты: поиск, переименование, удаление (с подтверждением в интерфейсе), дублирование.
- В центре — диалог: сообщения и живая лента агентов (статус, длительность, раскрываемый результат), один композер с выбором модели и усилия («Авто» по умолчанию), Стоп.
- Справа — превью с рамками устройств, вид «Код» с подсветкой и правкой, версии с восстановлением и сравнением «до / после», правка текста прямо в превью, скачивание HTML (в артефакте — возможность `downloads`), копирование, полный экран.
- Пустое состояние — большой композер с логотипом и несколькими идеями-подсказками: клик только вставляет текст в поле.
- Горячие клавиши: ⌘/Ctrl+Enter — отправить, Esc — остановить, ⌘/Ctrl+K — поиск по проектам, ⌘/Ctrl+S — скачать, ⌘/Ctrl+Z (вне полей) — предыдущая версия.
- Сайт без ключей: студия показывает состояние «Подключите ключ» со списком переменных окружения Vercel.

## 8. Дизайн-система

- Углы — continuous squircle: `corner-shape: squircle` внутри `@supports`, с увеличенным радиусом; без поддержки — обычный `border-radius`.
- Логотип — граненая призма, раскладывающая белый луч в спектр; SVG, читается от 16 до 128 px, светлая и тёмная версии; навигация, фавикон `public/effect/icon.svg`, студия.
- Движение — пружинящие кривые (`cubic-bezier(.2,.9,.25,1.15)` для «пружины», `cubic-bezier(.2,.8,.2,1)` для выхода), поэтапное появление, View Transitions при смене панелей студии, микро-взаимодействия только на `transform`/`opacity`.
- Призма — несколько слоёв глубины с разной скоростью параллакса, только `transform`/`opacity`, пауза вне экрана, без тяжёлых фильтров. Цель — ≥ 55 FPS на iPhone 13 (симуляция).

## 10. Журнал
